# lab-tool
 
電気化学研究室向けのデータ処理・可視化ツール集です。  
CHI604E ポテンショスタットで取得した測定データを Excel 上で自動処理・グラフ化します。
 
---
 
## ファイル構成
 
| ファイル名 | 説明 |
|---|---|
| `CVグラフ化マクロ.bas` | CV（サイクリックボルタンメトリー）データの自動処理マクロ |
| `LSVグラフ化マクロ.bas` | LSV（リニアスイープボルタンメトリー）データの自動処理マクロ |
| `モル計算アプリ.py` | モル数・濃度計算ツール |
 
---
 
## CV マクロ（CVグラフ化マクロ.bas）
 
### 機能
- CHI604E が出力する `.txt` ファイルを複数選択して一括読み込み
- サイクル 3 のデータを自動抽出（LOW 折り返し点を検出）
- 電流密度（μA/cm²）に自動変換
- 複数ファイルを 1 つのグラフに重ね描き
- カンマ区切り・タブ区切りの両フォーマットに対応
### グラフ仕様
- X 軸：E / V vs. RHE
- Y 軸：j / μA cm⁻²（固定スケール：−80 〜 80、ステップ 20）
- フォント：Times New Roman
### 使い方
1. Excel で `.bas` ファイルをインポート（VBA エディタ → ファイル → インポート）
2. マクロ `ImportCVData` を実行
3. ファイル選択ダイアログで `.txt` ファイルを選択（Ctrl+クリックで複数選択可）
4. 黄色セル（B2〜B4）で以下を確認・変更
   - **B2**：電極面積（cm²）　例：0.048
   - **B3**：開始電位（V）　※メタデータがあれば自動入力
   - **B4**：スイープセグメント数　※メタデータがあれば自動入力

## LSV マクロ（LSVグラフ化マクロ.bas）
 
### 機能
- CHI604E が出力する `.txt` ファイルを複数選択して一括読み込み
- 電流密度（mA/cm²）に自動変換
- 複数ファイルを 1 つのグラフに重ね描き
- カンマ区切り・タブ区切りの両フォーマットに対応
### グラフ仕様
- X 軸：E / V vs. RHE（上側表示）
- Y 軸：j / mA cm⁻²（固定スケール：−7 〜 0、ステップ 1）
- フォント：Times New Roman
### 使い方
1. Excel で `.bas` ファイルをインポート
2. マクロ `ImportLSVData` を実行
3. ファイル選択ダイアログで `.txt` ファイルを選択（Ctrl+クリックで複数選択可）
4. 黄色セル（B2）で電極面積（cm²）を確認・変更
   - **B2**：電極面積（cm²）　例：0.048
### 注意
`CalcNiceAxis` サブルーチンは CV マクロ側に定義されています。  
LSV マクロ単体で使用する場合は、CVグラフ化マクロの `CalcNiceAxis` を LSVグラフ化マクロにも貼り付けてください。
 
---
 
## 動作環境
 
- Microsoft Excel（Windows）
- CHI604E ポテンショスタット出力ファイル（`.txt`）
---
 
## 注意事項
 
- 電極面積（B2）はデフォルト値として `0.048 cm²` が設定されています。実際の電極面積に合わせて変更してください。
- CHI604E のメタデータ（Init E、Segment 数）がファイルに含まれている場合、B3・B4 は自動入力されます。
